# BizMetrics Assistant — Custom GPT Hands-On Topic 13

## Project Overview

BizMetrics Assistant is a data-analysis assistant designed for non-technical business users.

The assistant is designed to analyze uploaded CSV or spreadsheet data, perform calculations using a data-analysis tool such as Code Interpreter, identify data-quality issues, ask clarification questions when objectives are unclear, and explain findings in plain business language.

The project demonstrates:

- Objective confirmation
- Data-quality validation
- Missing-value handling
- Duplicate detection
- Calculation and aggregation
- Tool governance
- Anti-fabrication guardrails
- Plain-language reporting
- Ambiguous-question handling
